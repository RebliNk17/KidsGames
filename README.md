# 🎈 משחקים ולומדים - משחקי למידה לילדים

אתר משחקי למידה לילד בן 6 (ומעלה!): **חשבון** וגם **אותיות ומילים** - בהדרגה,
עם צלילים, אנימציות, הסברים קוליים בעברית, ואפשרות התקנה כאפליקציה על הטלפון (PWA).

**אין תלות בשרת** - הכול HTML/CSS/JS נקי, עובד גם בלי אינטרנט אחרי הביקור הראשון.

## 🚀 איך מפעילים

### מקומית
```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```
(אפשר גם לפתוח את `index.html` ישירות, אבל התקנה כאפליקציה ועבודה בלי רשת דורשות שרת/HTTPS.)

### GitHub Pages (מומלץ - חינם)
1. בריפו: **Settings ← Pages**
2. תחת Source לבחור **Deploy from a branch**, לבחור את ברנץ' `main` ותיקייה `/ (root)`
3. תוך דקות האתר יעלה ל-`https://<username>.github.io/KidsGames/`

כל הנתיבים באתר יחסיים, כך שהוא עובד גם תחת תת-נתיב של Pages.

### התקנה כאפליקציה במכשיר
- **אנדרואיד (Chrome):** ייפתח כפתור "📲 התקן כאפליקציה" במסך הבית, או: תפריט ⋮ ← "הוספה למסך הבית".
- **אייפון (Safari):** כפתור שיתוף ← "הוסף למסך הבית".
- **מכשיר ישן שאי אפשר להתקין בו?** בפינת מסך הבית יש כפתור **מסך מלא** ⛶ -
  הוא עובד גם בדפדפני אנדרואיד ישנים, המצב נשמר, נכנס אוטומטית בכל כניסה למשחק,
  ואם הילד יצא בטעות (מחוות "אחורה") - הנגיעה הבאה במסך מחזירה אותו. כיבוי - דרך אותו כפתור.

### חלון רמות מתגלגל
בכל רגע פעילות עד **5 רמות** במקביל, והתרגילים נבחרים מתוכן (עם עדיפות לרמה החדשה).
כשעולים רמה - הרמה הקלה ביותר יוצאת מהחלון: היינו ב-1‑5 ועלינו ל-6? עכשיו משחקים ב-2‑6.

### עליית רמה והסברים קוליים
- כל תשובה נכונה **בניסיון הראשון** = ⭐. צוברים **7 כוכבים** - עולים רמה!
- בעליית רמה מופיע חלון חגיגי עם **הסבר מוקרא בקול** (קול עברי של הדפדפן) + דוגמה פתורה.
- אפשר לשמוע את ההסבר שוב ושוב (🔊 שמע שוב), וגם באמצע המשחק - כפתור ❓ מסביר את התרגיל הנוכחי.
- כל שאלה מוקראת אוטומטית, וכפתור 🔊 מקריא שוב - כי הילד עוד לא קורא.

### מניעת ניחושים 🤔
- עם הופעת שאלה הכפתורים **נעולים ל-3 שניות** ("רגע חושבים...") עם טבעת ספירה לאחור.
- אחרי טעות - נעילה של 4 שניות נוספות, והכפתור השגוי נפסל.
- טעות שנייה ← **רמז קולי** מותאם לתרגיל. טעות שלישית ← התשובה הנכונה מהבהבת ולוחצים עליה ביחד (בלי כוכב).
- תשובה נכונה אחרי טעות ממשיכה הלאה אבל לא מזכה בכוכב - אין רווח בניחוש.
- בתרגילי ספירה אפשר **ללחוץ על הציורים** - כל לחיצה מסמנת, משמיעה תו ואומרת את המספר.

### החלטות פדגוגיות חשובות (למי שירצה להרחיב)
- **אותיות שנשמעות אותו דבר** (א/ע, כ/ק/ח, ט/ת, ס/ש, ב/ו) לעולם לא מופיעות
  כמסיחים זו של זו בתרגילי צליל - שלא תהיה תשובה "נכונה גם" שנפסלת.
- **בתרגילי קריאה אין הקראה של המילה** - רק של ההוראה. אחרת אין קריאה.
  רק אחרי שתי טעויות מגיע רמז ("מתחיל כמו..."), כדי שקודם ינסה לפענח.
- **מסיחי הקריאה מתחילים באותה אות** כשאפשר - אי אפשר לנחש רק לפי האות הראשונה.
- **צלילי ניקוד בהקראה** נכתבים באיות שקול הדפדפן הוגה נכון (בָּ ← "בה",
  בִּ ← "בי", בּוֹ ← "בו"); סגול/צירה/שורוק נלמדים לפי שם + תיאור הצורה,
  כי אין דרך אמינה להשמיע אֶ/אוּ בכל קול.
- **בכל חלון הסבר יש כרטיסים לחיצים** - הילד יכול לשמוע כל אות/צליל שוב ושוב.
- מאגר המילים כולו **מנוקד, עם אמוג'י ומספר הברות** - מוגדר ב-`js/letters-levels.js`
  וקל להוסיף מילים.

### שמירת התקדמות
ההתקדמות בכל משחק נשמרת בנפרד (רמה, כוכבים, סטטיסטיקות) ב-`localStorage` של
המכשיר - גם אחרי רענון, סגירה או כיבוי. ילד אחד = פרופיל אחד. יציאה באמצע?
חוזרים בדיוק לאותה רמה.

### אזור הורים 🔒
**לחיצה ארוכה (1.5 שניות)** על ⚙️ במסך הבית:
- הפעלה/כיבוי של צלילים ודיבור + בדיקת קול
- שינוי ידני של הרמה (למעלה/למטה)
- סטטיסטיקות הצלחה
- איפוס מלא

## 🗂️ מבנה הקוד

```
index.html              מסכי המשחק (בית, משחק, הסבר, הגדרות)
css/style.css           עיצוב + כל האנימציות
js/engine.js            ★ מנוע המשחקים המשותף: חלון רמות, כוכבים, נעילת חשיבה,
                          רמזים, חלונות הסבר. כל משחק הוא קונפיגורציה שלו.
js/levels.js            20 רמות החשבון: מחוללים, הסברים, רמזים (טהור, בלי DOM)
js/game.js              משחק החשבון: רנדור + חיבור למנוע
js/letters-levels.js    20 רמות האותיות: אותיות, ניקוד, מאגר מילים, מחוללים (טהור)
js/letters-game.js      משחק האותיות: רנדור, בניית מילים, דוגמאות לחיצות
js/app.js               מצב ושמירה (פרוסה לכל משחק), ניווט, אזור הורים, PWA
js/speech.js            הקראה בעברית (Web Speech API)
js/sounds.js            צלילים מסונתזים (Web Audio API, בלי קבצי אודיו)
js/confetti.js          קונפטי וכוכב מעופף
sw.js                   Service Worker - משחק גם בלי אינטרנט
manifest.webmanifest    הגדרות התקנה כאפליקציה
tools/make_icons.py     יצירת האייקונים (stdlib בלבד): python3 tools/make_icons.py
tests/levels.test.js    בדיקת מחוללי החשבון:  node tests/levels.test.js
tests/letters.test.js   בדיקת מחוללי האותיות: node tests/letters.test.js
```

### כוונון מהיר (בראש `js/engine.js`)
| קבוע | ברירת מחדל | משמעות |

| `STARS_PER_LEVEL` | 7 | כוכבים לעליית רמה |
| `WINDOW_SIZE` | 5 | כמה רמות פעילות במקביל |
| `THINK_MS` | 3000 | זמן חשיבה חובה לפני מענה |
| `RETRY_MS` | 4000 | זמן חשיבה אחרי טעות |

### הוספת רמה חדשה
מוסיפים אובייקט למערך `LEVELS` (ב-`js/levels.js` לחשבון או `js/letters-levels.js`
לאותיות) עם `name`, `icon`, `explain` (הטקסט המוקרא), דוגמה להסבר (`demo()` בחשבון,
`demoSpec` באותיות) ו-`gen()` (מחולל תרגילים) - והכול מתחבר לבד: חלון הרמות,
ההסברים והמדבקות. מריצים את הבדיקות ב-`tests/` לוודא.

### עדכון גרסה
אחרי שינוי קבצים באתר - מעלים את מספר הגרסה ב-`sw.js` (`kidsgames-v1` ← `v2`)
כדי שמכשירים שהתקינו את האפליקציה יקבלו את העדכון.

## 🚀 בהמשך הדרך
- משחקים נוספים: המנוע המשותף (`js/engine.js`) מוכן - משחק חדש = קובץ רמות + קובץ רנדור.
- הקול: כרגע קול עברי של הדפדפן/המכשיר. אפשר בעתיד להחליף להקלטות או קול AI איכותי -
  נקודת החיבור היחידה היא `js/speech.js`.
