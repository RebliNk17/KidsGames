# 🎈 משחקים ולומדים - משחקי חשבון לילדים

אתר משחקי למידה לילד בן 6 (ומעלה!): לומדים חשבון בהדרגה, עם צלילים, אנימציות,
הסברים קוליים בעברית, ואפשרות התקנה כאפליקציה על הטלפון (PWA).

**אין תלות בשרת** - הכול HTML/CSS/JS נקי, עובד גם בלי אינטרנט אחרי הביקור הראשון.

## 🚀 איך מפעילים

### מקומית
```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```
(אפשר גם לפתוח את `index.html` ישירות, אבל התקנה כאפליקציה ועבודה בלי רשת דורשות שרת/HTTPS.)

### GitHub Pages (מומלץ - חינם)
1. בריפו: **Settings ← Pages**
2. תחת Source לבחור **Deploy from a branch**, לבחור את ברנץ' `main` ותיקייה `/ (root)`
3. תוך דקות האתר יעלה ל-`https://<username>.github.io/KidsGames/`

כל הנתיבים באתר יחסיים, כך שהוא עובד גם תחת תת-נתיב של Pages.

### התקנה כאפליקציה במכשיר
- **אנדרואיד (Chrome):** ייפתח כפתור "📲 התקן כאפליקציה" במסך הבית, או: תפריט ⋮ ← "הוספה למסך הבית".
- **אייפון (Safari):** כפתור שיתוף ← "הוסף למסך הבית".

### חלון רמות מתגלגל
בכל רגע פעילות עד **5 רמות** במקביל, והתרגילים נבחרים מתוכן (עם עדיפות לרמה החדשה).
כשעולים רמה - הרמה הקלה ביותר יוצאת מהחלון: היינו ב-1‑5 ועלינו ל-6? עכשיו משחקים ב-2‑6.

### עליית רמה והסברים קוליים
- כל תשובה נכונה **בניסיון הראשון** = ⭐. צוברים **7 כוכבים** - עולים רמה!
- בעליית רמה מופיע חלון חגיגי עם **הסבר מוקרא בקול** (קול עברי של הדפדפן) + דוגמה פתורה.
- אפשר לשמוע את ההסבר שוב ושוב (🔊 שמע שוב), וגם באמצע המשחק - כפתור ❓ מסביר את התרגיל הנוכחי.
- כל שאלה מוקראת אוטומטית, וכפתור 🔊 מקריא שוב - כי הילד עוד לא קורא.

### מניעת ניחושים 🤔
- עם הופעת שאלה הכפתורים **נעולים ל-3 שניות** ("רגע חושבים...") עם טבעת ספירה לאחור.
- אחרי טעות - נעילה של 4 שניות נוספות, והכפתור השגוי נפסל.
- טעות שנייה ← **רמז קולי** מותאם לתרגיל. טעות שלישית ← התשובה הנכונה מהבהבת ולוחצים עליה ביחד (בלי כוכב).
- תשובה נכונה אחרי טעות ממשיכה הלאה אבל לא מזכה בכוכב - אין רווח בניחוש.
- בתרגילי ספירה אפשר **ללחוץ על הציורים** - כל לחיצה מסמנת, משמיעה תו ואומרת את המספר.

### שמירת התקדמות
ההתקדמות (רמה, כוכבים, סטטיסטיקות) נשמרת ב-`localStorage` של המכשיר - גם אחרי רענון,
סגירה או כיבוי. ילד אחד = פרופיל אחד. יציאה באמצע? חוזרים בדיוק לאותה רמה.

### אזור הורים 🔒
**לחיצה ארוכה (1.5 שניות)** על ⚙️ במסך הבית:
- הפעלה/כיבוי של צלילים ודיבור + בדיקת קול
- שינוי ידני של הרמה (למעלה/למטה)
- סטטיסטיקות הצלחה
- איפוס מלא

## 🗂️ מבנה הקוד

```
index.html            מסכי המשחק (בית, משחק, הסבר, הגדרות)
css/style.css         עיצוב + כל האנימציות
js/levels.js          ★ 20 הרמות: מחוללי תרגילים, הסברים, רמזים (טהור, בלי DOM)
js/game.js            מנוע המשחק: חלון רמות, נעילת חשיבה, כוכבים, עליית רמה
js/app.js             מצב ושמירה, ניווט, אזור הורים, התקנת PWA
js/speech.js          הקראה בעברית (Web Speech API)
js/sounds.js          צלילים מסונתזים (Web Audio API, בלי קבצי אודיו)
js/confetti.js        קונפטי וכוכב מעופף
sw.js                 Service Worker - משחק גם בלי אינטרנט
manifest.webmanifest  הגדרות התקנה כאפליקציה
tools/make_icons.py   יצירת האייקונים (stdlib בלבד): python3 tools/make_icons.py
tests/levels.test.js  בדיקת כל המחוללים: node tests/levels.test.js
```

### כוונון מהיר (בראש `js/game.js`)
| קבוע | ברירת מחדל | משמעות |
|-------|-----|---------|
| `STARS_PER_LEVEL` | 7 | כוכבים לעליית רמה |
| `WINDOW_SIZE` | 5 | כמה רמות פעילות במקביל |
| `THINK_MS` | 3000 | זמן חשיבה חובה לפני מענה |
| `RETRY_MS` | 4000 | זמן חשיבה אחרי טעות |

### הוספת רמה חדשה
מוסיפים אובייקט למערך `LEVELS` ב-`js/levels.js` עם `name`, `icon`, `explain`
(הטקסט המוקרא), `demo()` (דוגמה קבועה להסבר) ו-`gen()` (מחולל תרגילים) - והכול
מתחבר לבד: חלון הרמות, ההסברים והמדבקות. מריצים `node tests/levels.test.js` לבדיקה.

### עדכון גרסה
אחרי שינוי קבצים באתר - מעלים את מספר הגרסה ב-`sw.js` (`kidsgames-v1` ← `v2`)
כדי שמכשירים שהתקינו את האפליקציה יקבלו את העדכון.
